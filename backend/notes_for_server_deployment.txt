We combine the frontend and backend.

We no longer reference localhost:3000 for the home page.

Instead: we reference localhost.fuqua.duke.edu:5001 for the home page.



To build the project:

From the frontend folder:
npm run build

Rename the build folder to 'react_build', copy it in at the project_home level in the backend
